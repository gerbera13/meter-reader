# Показания электросчётчиков

## Что делает программа
Помогает снимать показания с 4 электросчётчиков по адресам. Фотографируешь счётчик — программа распознаёт цифры и записывает в поле. Сравнивает с прошлым месяцем, предупреждает если расход подозрительный (>200 кВт·ч).

## Как запустить

1. Открыть LM Studio → вкладка Chat → загрузить модель `qwen3-vl-8b-instruct`
2. LM Studio → вкладка Developer → Start Server (зелёный)
3. Терминал: `cd /Users/oksana/Documents/github && python3 server.py 8000`
4. Браузер: `http://localhost:8000/meter-reader.html`

## Как пользоваться

### Первый запуск
- Нажать **Тест-данные** — загрузятся предыдущие показания для сравнения

### Снятие показаний (один счётчик)
- Нажать 📷 рядом с нужным тарифом
- Выбрать фото счётчика
- Цифры подставятся автоматически

### Снятие показаний (все счётчики разом)
- Нажать **📷 Фото панели**
- Выбрать фото со всеми счётчиками
- Показания распределятся по свободным полям

### Следующий месяц
- Нажать **Сбросить** — текущие показания станут «предыдущими»
- Поменять дату в поле слева
- Загрузить новые фото

### Что значат цвета
- 🟢 Зелёная рамка — всё заполнено, расход в норме
- 🟠 Оранжевая рамка — подозрительный расход (>200 или меньше предыдущего)
- ⚪ Серый кружок — показания ещё не внесены

## Где лежат файлы
- `meter-reader.html` — основная программа
- `server.py` — прокси-сервер (обходит CORS)
- `test_meters/` — тестовые фото счётчиков
