# meter-reader.html — техническая спецификация

## Архитектура

```
meter-reader.html    — SPA (HTML+CSS+JS), вся логика на клиенте
server.py            — HTTP-прокси (Python http.server), порт 8000 → 127.0.0.1:1234
LM Studio            — сервер модели qwen3-vl-8b-instruct, порт 1234, OpenAI-compatible API
```

Запросы от браузера идут на `/proxy/v1/chat/completions` → сервер проксирует на `http://127.0.0.1:1234/v1/chat/completions`. Нужно из-за CORS.

## API

### Распознавание (OpenAI-совместимый)


## Основные функции

### renderMeters()
- Перестраивает DOM метриков
- Для каждого счётчика: заголовок (адрес + номер), строки тарифов, фото
- Вешает обработчики на кнопки 📷 и поля ввода

### Обработчик фото панели (panelInput.onchange)
1. readAsDataURL → сжатие до 1200px, JPEG 0.7
2. fetch к API с промптом для списка показаний
3. Парсинг ответа: строки вида "T1: 32548" → массив значений
4. Заполнение слотов по порядку: T1 все → T2 все → T3 все
5. Проверка дубликатов (уже внесено)
6. Расчёт разницы с предыдущим, предупреждения
7. Сохранение фото для заполненных тарифов
8. Обновление UI

### Сброс (resetBtn)
- Переносит текущие value → prev
- Очищает value, date, photo
- Предыдущие показания сохраняются

### Обнулить (clearBtn)
- Полная очистка localStorage
- Все данные теряются

## Генерация тестовых изображений
Скрипт на Python без внешних библиотек — рисует BMP счётчиков попиксельно, конвертирует в PNG через `sips`.

Конфигурация счётчиков (METERS):
- 1 тариф: Садовая, Парковая
- 2 тарифа: Рябиновая
- 3 тарифа: Лесная
