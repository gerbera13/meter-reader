# Распознавание показаний электросчётчиков

Веб-приложение, которое считывает показания с фотографии счётчика и заполняет
таблицу вместо ручного ввода. Работает **полностью локально**: снимки никуда
не отправляются, нейросеть запущена на своём компьютере.

Личный проект.

---

## Что делает

Сфотографировали счётчик — программа распознала цифры и подставила их в поле.
Можно снять сразу всю панель: показания распределятся по свободным полям.

- Поддержка одно-, двух- и трёхтарифных счётчиков
- Распознавание общей панели с автоматическим распределением значений
- Сравнение с показаниями за прошлый месяц
- Предупреждение об аномальном расходе — свыше 200 кВт·ч или меньше предыдущего
- Защита от повторного ввода: уже внесённые показания не перезаписываются
- Хранение между сессиями, ручная правка любого поля

## Как устроено

```
Браузер  →  localhost:8000 (прокси)  →  localhost:1234 (LM Studio)  →  Qwen3-VL
```

| Компонент | Технология |
|---|---|
| Интерфейс | JavaScript, Canvas API (сжатие и нарезка изображений) |
| Модель | Qwen3-VL-8B-Instruct, запущена локально в LM Studio |
| Обращение к модели | OpenAI-совместимый API (`/v1/chat/completions`) |
| Прокси-сервер | Python 3, `http.server` — обходит ограничение CORS |
| Хранение | `localStorage` браузера |

## Запуск

Нужен [LM Studio](https://lmstudio.ai) и Python 3.

1. LM Studio → вкладка **Chat** → загрузить модель `qwen3-vl-8b-instruct`
2. LM Studio → вкладка **Developer** → **Start Server**
3. В терминале:

```bash
python3 server.py 8000
```

4. Открыть в браузере `http://localhost:8000/meter-reader.html`

Кнопка **Тест-данные** заполнит предыдущие показания, чтобы было с чем сравнивать.

## Ограничения

- Требует запущенного LM Studio с загруженной моделью — без него распознавание
  не работает, остаётся только ручной ввод
- Данные хранятся в `localStorage`: очистка данных сайта в браузере их удалит
- Точность зависит от качества снимка; поля всегда можно поправить руками
